### Описание

Данный раздел содержит фото и метаданные с первичной геопривязкой с обзорных камер, размещенных на космических аппаратах из состава группировки СПУТНИКС, а также изображения, не снабженные сопроводительными метаданными. В процессе развития портала он будет пополняться снимками с любых КА, выполненных на кубсат-платформе СПУТНИКС.

Представленные снимки имеют следующие характеристики:

- Формат и разрешение файла: JPEG, RGB 24бит, 3280 x 2464 пикселя
- Полоса обзора: 670 км (гориз.) на 500 км (верт.)
- Пространственное разрешение по горизонтали: 200 м/пиксель (типовое)\*
- Пространственное разрешение по вертикали: 200 м/пиксель (типовое)\*
- Все съемки на всех спутниках выполняются с одинаковыми настройками камер по выдержке и усилению. Радиометрическая, спектральная и геометрическая калибровки камер не проводились.

 *\* - точные величины зависят от конкретного снимка: высоты орбиты, поворота КА при съемке и т.д. Для каждого конкретного снимка надо ориентироваться на рассчитанные по телеметрии координаты углов в сопроводительном файле KML.* 

Описание платформы Спутникс, лежащей в основе КА:  
[SXC3-GA-ADC-XB](https://sputnix.ru/ru/platformyi/cubesat-platformy/sputnikovaya-platforma-orbikraft-pro-3u-modifikacziya-profi-x)

### Сценарии использования

Материалы на данном портале формируются исходя из следующих типовых пользовательских сценариев:

- Визуальное изучение по карте - выполнить наложение всех или новых снимков на карту в [Google Earth Pro](https://www.google.com/earth/about/versions/#earth-pro) и изучать изображения в выбранном районе. 
- Автоматическая обработка пользовательскими алгоритмами - наиболее интересная для нас область, но и наиболее наукоемкая. 
- Визуальный просмотр - просто открыть перед работой красивые фото нашей планеты и получить эстетическое удовольствие. 
- Ручная художественная обработка - выбрать особенные фотографии и сделать для них обработку в графическом редакторе публикаций или статей.

Мы надеемся, что наиболее успешные исследовательские группы смогут разработать автоматические конвейеры для пост-обработки полученных данных, реализующие, например: геопривязку по опорным объектам, топологическую коррекцию, радиометрическую коррекцию, расчет индексов вегетации и др.

В случае успешной реализации пост-обработки СПУТНИКС готов поддержать такие группы, а также добавить данную автоматическую обработку на сервер этого портала, чтобы дать другим исследователям больше данных для работы.

Возможные использования данных не ограничиваются перечисленными сценариями, пользователи могут сами придумывать удобный для них формат работы.

#### Визуальное изучение по карте

Для визуализации данных предусмотрена возможность выполнить наложение всех или части снимков на карту и изучать изображения в выбранном районе. 

::: info
Можно использовать фильтр по кнопке "Modified" для просмотра только новых данных, а также сортировку по колонке "Size" (по возрастанию) для выгрузки сначала только областей съемки. 

Для массовой выгрузки можно использовать флаг в верхней левой части таблицы, после его установки рядом появится кнопка "Download" для загрузки всей выборки. 

После загрузки и разархивации файлов можно открыть программу [Google Earth Pro](https://www.google.com/earth/about/versions/#earth-pro), выбрать все файлы KML в проводнике и просто перетащить их в окно программы (браузера) - на карте автоматически появятся области фотографирования или изображения (если JPEG были скачаны и лежат в одной папке с KML-файлами). 

Для наложенных на карту снимков в Google Earth Pro можно вручную уточнять геопривязку, перемещая мышью углы фотографии (выбрать в дереве "Метки" фото, правой кнопкой мыши выбрать "Свойства", после чего на фото появятся перемещаемые маркеры. Можно также менять прозрачность фото ползунком в открывшемся окне "Редактирование Наложения"). Модифицированные файлы можно сохранить в новый KML файл (правой кнопкой на узел в дереве "Метки"->сохранить местоположение как...->выбрать "Тип файла" KML, ввести имя->Сохранить).

:::

#### Автоматическая обработка пользовательскими алгоритмами

Наиболее интересная для нас область, но и наиболее наукоемкая. Чтобы упростить работу автоматических алгоритмов пост-обработки и повысить точность мы разместили в файле KML дополнительные данные с телеметрией системы ориентации спутника в момент съемки (эти данные получены на Земле интерполяцией по общей телеметрии аппарата для времени съемки), их структура описана ниже в разделе "Техническое описание сопроводительных данных". Эти данные позволяют пользователю самостоятельно определить:

- местоположение спутника на орбите (группа полей latitude-longitude-altitude)
- ориентацию спутника в орбитальной системе координат (группа полей orb.quat.w/x/y/z) или в ECI (группа полей eci.quat.w/x/y/z) и угловую скорость (группа полей orb.AV_x/y/z). 
- время съемки указано в поле time, которое имеет формат posix_time (сек) \* 1000000 (мксек)
- параметры движения КА по орбите для данного времени можно получить, используя модель движения SGP4 и набор орбитальных элементов TLE из Интернет (например, из радиолюбительской сети [Соникс](https://sonik.space/satellites/) или с сайтов <https://celestrak.org/> и [https://www.space-track.org/](https://www.space-track.org/auth/login)).

## **Техническое описание сопроводительных данных**

**Structure of additional metadata from </Description> section of KML file**

*Example:
SXC3-2332;25_10_14 08:31:00.457;0;I;5;20;f210;125;OK;9d6225341a4106000002000057eb193f4c9e233fbd12273eb8e7e6be22d7843df3cd61bc2d9133be054af0333f5ad4be3ac30f363f3d5d593cd23ee4bde0097cbc713e81bd059152193f5f03243f7ddb293e71dde6be115bae3e3b1e87be13f03dbf0339b84e42cfb567c0e162d848080601bdfeb402a1fb0afec329e0*

{Satellite board ID};{date and time of packet recording};0;I;5;20;f210;125;OK;{adcs telemetry in hex}

***Adcs telemetry structure description:***
Object: **Packet**
Describes a single data packet for exchange.

Field - Type - Description - Note
PacType - List - Command type: datain – telemetry packet
PacId - Number - Unican two-byte message code (MsgId)
PacName - Text - Command name
PacDesc - Text - Command description
DataLen - Number - Command data length in bytes (besides MsgId)
Field<..> - Object - Data/command field description

Object: **Field**
Describes a single packet field.

Field - Type - Description - Note
FldType - List -
Field type:
int – unsigned integer (up to 64 bits);
uint – signed integer (up to 64 bits);
float – floating-point number (32 bits only);
double – floating-point number (64 bits only);
string – custom text;
data – random data (hex);
bit – single bit field;
time_t - 64-bit time (posix 32-time * 10e6 usec);
FldName - Text - Field name
FldDesc - Text - Field description
FldValue - Text - Field value. Depends on type
FldOffset - Number - Field offset relative to the beginning of the packet data in bits
FldLen - Number - Field length in bits
FldByteOrder - List - Type of representation of multibyte data in a packet: BE – big-endian, LE – little-endian
FldEdit - List - Ability to edit the field
