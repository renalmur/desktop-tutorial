Что делать с облачными снимками

Запуск

Выберите файлы или положите их в папку data/incoming.

Результатов пока нет

Выберите снимки в панели сверху и нажмите «Обработать снимки». Для каждого снимка нейросеть посчитает процент облачности и решит: сохранить или удалить.

Учебные снимки для пробы создаёт команда python tools/make_samples.py — они появятся в папке data/incoming.
